## 1. Fabrication
### 1.1 3D print bioreactor lid, sensor mounts, and gas manifold connector
**3D print the bioreactor lid and all sensor/actuator mounts.**
1. Print the Bioreactor Lid (Main) using PETG with 30% infill, 0.2mm layer height, ensuring watertightness.
2. Print the pH Sensor Mount and Temperature Sensor Mount using PETG with 20% infill and 0.2mm layer height.
3. Print two Gas Manifold Connectors using PETG with 40% infill and 0.2mm layer height.
4. Print the Gas Storage Level Sensor Mount and Bioreactor Heating Element Mount using PETG with 30% infill, 0.2mm layer height, and 4 perimeters.
5. Inspect all printed parts for dimensional accuracy, layer adhesion, and any printing defects.
